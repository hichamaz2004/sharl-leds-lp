🏢 LOGOS — Client Logos Strip
================================
Place your client company logo images here.

Supported formats: .png  .svg  .webp  (PNG with transparent background recommended)

Recommended size: any width × 48px height (will be scaled uniformly)

Then update src/components/LogosStrip.tsx — replace the `moroccanBrands` array entries
with image-based logos:

  { name: 'Maroc Telecom', src: '/logos/maroc-telecom.png' }

Files in this folder are served at:
  /logos/your-logo.png
