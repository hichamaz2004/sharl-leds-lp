📸 SCREENSHOTS — Results Section
==================================
Place your campaign result screenshots here.

Supported formats: .jpg  .jpeg  .png  .webp

Recommended size: 1280×800px (16:10 ratio)

Then update src/components/Results.tsx — find the `screenshots` array at the top
and set the `src` field for each card:

  { src: '/screenshots/facebook-roas.jpg', label: 'Facebook Ads — ROAS 4.7x', ... }

Files in this folder are served at:
  /screenshots/your-file.jpg
